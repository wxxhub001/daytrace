# 发布操作手册

本地仓库已经准备好（2 个提交，工作区干净）。下面 6 步做完，App 就能被别人下载。

---

## 第 1 步：在 GitHub 建仓库

打开 https://github.com/new

- **Repository name**：`daytrace`
- **Description**：`刷够了没 · 纯本地 Android 屏幕时间管理，不联网不收集数据`
- **Public** ✅
- **不要勾** Add a README / .gitignore / license（本地已有，勾了会冲突）

点 Create repository。

---

## 第 2 步：生成访问令牌（Token）

GitHub 不接受账号密码，push 需要 Token：

1. 打开 https://github.com/settings/tokens
2. **Generate new token (classic)**
3. Note 填 `daytrace push`，Expiration 选 90 天
4. 勾选 **`repo`**（整个区块）
5. 生成后**立刻复制**（只显示一次）

---

## 第 3 步：推上去

在 `AppTrack` 目录下执行：

```bash
git remote add origin https://github.com/WXXHUB001/daytrace.git
git branch -M main
git push -u origin main
```

弹出登录时：

- Username：`WXXHUB001`
- Password：**粘贴第 2 步的 Token**（不是账号密码）

> 想省掉每次输入：`git config --global credential.helper manager`（Windows 会弹窗记住）

---

## 第 4 步：开 GitHub Pages（让隐私政策有公开网址）

1. 仓库 → **Settings** → 左侧 **Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 `main`，目录选 **`/ (root)`**，Save
4. 等 1–2 分钟，隐私政策地址就是：

```
https://wxxhub001.github.io/daytrace/PRIVACY
```

**验证**：浏览器打开这个地址，能看到隐私政策页面，而不是一堆 `#` 号才算成功。

> 为什么用 Pages 而不是 raw 链接：raw 返回的是纯文本文件（`text/plain`），部分商店后台会判定"不是网页"而拒绝收录。

---

## 第 5 步：发 Release（这是别人下载的地方）

1. 仓库 → 右侧 **Releases** → **Draft a new release**
2. **Choose a tag**：输入 `v1.9` → 点 `Create new tag: v1.9 on publish`
3. **Release title**：`v1.9 — 第一个官方正式版`
4. **Describe this release**：把 `RELEASE_NOTES_v1.9.md` 的全部内容粘进去
5. **Attach binaries**：把 `DayTrace-v1.9-release.apk` 拖进去
6. 点 **Publish release**

发布后下载地址就是：

```
https://github.com/WXXHUB001/daytrace/releases/latest
```

**注意**：只传 `-release.apk`，别传 debug 包（签名不同，用户装错会互相覆盖失败）。

---

## 第 6 步：自测一遍

拿一台**没装过这个 App** 的手机（或用别的账号）：

1. 打开 `https://github.com/WXXHUB001/daytrace/releases/latest`
2. 下载 APK → 安装 → 允许未知来源
3. 走完授权引导
4. 打开「我的 → 支持一下 → 请我喝杯奶茶」，确认二维码能显示
5. 用另一台手机扫一下，确认能打开微信付款页（**别真付，看一眼金额是否为任意**）

---

## 之后每次发新版

```bash
# 1. 改 app/build.gradle.kts 里的 versionCode +1、versionName
# 2. 出包
bash tools/build-release.sh

# 3. 提交
git add -A && git commit -m "v1.10：改了什么"
git push

# 4. 去 GitHub 发新 Release，附上新的 APK
```

⚠️ **versionCode 必须递增**，否则用户装了新版还是显示旧版。
⚠️ **始终用同一个 keystore**（`keystore/daytrace-release.jks`），换了用户就再也无法更新。

---

## 出问题怎么办

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| push 报 `Authentication failed` | 用了账号密码 | 改用 Token |
| push 报 `remote already has commits` | 建仓库时勾了 README | `git pull --rebase origin main` 后重推 |
| Pages 打开是 `#` 原文 | Pages 还在构建，或选错分支 | 等 2 分钟；确认 Branch=main、目录=/ |
| 用户装新版提示"未安装" | 签名不一致 | 确认发的是 release 包，且 keystore 没换 |
| Release 里 APK 下载后打不开 | 上传了 debug 包 | 重新上传 `-release.apk` |
